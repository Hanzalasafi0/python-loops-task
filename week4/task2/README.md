# Student Management System

## 📌 Project Description
This is a simple Student Management System developed using Python. It allows users to add, view, and search student records through a menu-driven interface.

## 🚀 Features
- Add Student Details
- View All Students
- Search Student by Name
- Easy Menu-Driven Program

## 🛠️ Technologies Used
- Python 3

## 📂 Project Files
- student_management_system.py
- README.md
- output_screenshot.png

## ▶️ How to Run
1. Open the project in VS Code or any Python IDE.
2. Run the `student_management_system.py` file.
3. Follow the menu options shown on the screen.
